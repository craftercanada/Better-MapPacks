BetterMapPacks

BetterMapPacks improves Geometry Dash map pack progression by showing recommended levels to complete before attempting more difficult map packs.

 Features
- Displays progression guidance for map packs
- Helps players know what levels to beat before harder difficulties
- Focuses on smoother progression toward Beginner Extreme map packs
- Lightweight UI integrated into the map packs menu

 Why?
Map pack are boring for new players. This mod helps guide players through a more exicting  difficulty progression instead of playing the boring map packs.
