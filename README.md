
BetterMapPacks improves Geometry Dash map pack progression by showing milestone progress directly in the main menu.

Features
Shows progression milestones for:
Stars
Demons
Secret Coins
User Coins
Diamonds
Displays current progress toward the next configured milestone
Lightweight UI integrated into the main menu
Customizable milestone intervals
Why?
Map packs are often ignored by players because progression feels disconnected from the rest of the game. 
This mod helps make map packs feel more rewarding and connected to overall account progression
